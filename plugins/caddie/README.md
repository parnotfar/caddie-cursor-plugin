# Caddie — Cursor plugin

This folder is the **Caddie** Cursor Marketplace plugin. It provides rules and skills so the Cursor agent uses Caddie commands and follows Caddie codebase conventions.

The skills use the installed CLI for live module discovery. They do not duplicate command catalogs or assume optional plugins are part of core.

- **Rules**: `rules/*.mdc`
- **Skills**: `skills/*/SKILL.md`
- **Manifest**: `.cursor-plugin/plugin.json`
- **Logo**: `assets/logo.svg`

See the [repo root README](../../README.md) for install and validation.
